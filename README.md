# My Portfolio

**Live Demo:** [https://souradeepdasportfolio.vercel.app/](https://souradeepdasportfolio.vercel.app/)

This is my professional portfolio website, showcasing my work experience, technical skills, and key projects.

## Sections
- **Home**: A brief introduction and quick links to my GitHub and LinkedIn.
- **Projects**: Highlights of my recent work, including the AlgoTradeX platform and AI Desktop Assistant.
- **History**: My professional journey, including my apprenticeship at Bank of America and internship at Accenture.
- **Skills**: A breakdown of my technical expertise in languages, frameworks, and tools.

## Tech Stack
- **Frontend**: React, TypeScript, Framer Motion
- **Styling**: CSS Modules
- **Icons**: React Icons
- **Scroll Handling**: React Scroll, React Intersection Observer

Built with ❤️ using Vite.
